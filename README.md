# Newspaper Web App

Веб-приложение интернет-газеты, реализующее публикацию новостных статей, регистрацию и аутентификацию пользователей, возможность оставлять комментарии к статьям и лайкать их. Также в системе предусмотрена административная панель для управления статьями и комментариями.

## Стек

**Backend**  
  - Java 8  
  - Spring Boot
  - JWT для аутентификации  
  - Hibernate + JPA  
  - PostgreSQL  

**Frontend**  
  - Vue.js  

## Требования к окружению

- Java 8 или выше  
- Node.js
- PostgreSQL  
- Docker (опционально)

## Сборка 1
   ```sh 
   docker-compose up --build
   ```

## Сборка 2
- **Backend**  
   ```sh 
   cd TheNews-backend   
   mvn clean package   
   mvn spring-boot:run   
   ```
   или после сборки 

   ```sh 
   java -jar target/TheNews-0.0.1-SNAPSHOT.jar
   ```
- **Frontend**  
    ```sh 
    cd TheNews-frontend
    npm install
    npm run build
    npm run serve
    ```
## Основные страницы

**Главная**  
  - Список новостей за последние 24 часа по убыванию даты публикации  
  - Кнопка «Показать больше» для длинных статей  
  - Лайки (для авторизованных пользователей - роль ROLE_USER)  
  - Просмотр комментариев по кнопке «Комментарии» 
  - Комментарии под статьёй:
    - По умолчанию 3 последних  
    - Кнопка «Ещё комментарии»  
    - Форма добавления нового комментария для авторизованных   

**Аутентификация/авторизация**  
  - Вход по email и паролю  
  - Перенаправление на главную при успешном входе  
  - Ссылка на страницу регистрации  

**Регистрация**  
  - Обязательные поля: имя, фамилия, email, пароль  
  - Email должен быть уникален  
  - Сообщение об успешной регистрации  

## Дополнительные возможности

**Админ-панель**  
  - CRUD для новостных статей  
  - Удаление комментариев  

**Тематики и фильтрация**  
  - Администратор задаёт тематики статьям  
  - Пользователь выбирает любимые и запретные темы  
  - Статьи выводятся в приоритете по совпадениям и исключаются по запретным тематикам
